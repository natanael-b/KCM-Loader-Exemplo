Esse exemplo ilustra como carregar os módulos de configuração do Plasma em uma aplicação Qt Widgets

## Dependências

Por padrão esse projeto depende apenas do KDE Plasma, não exigindo dependências em tempo de execução, porém para compilar são necessários:

#### No Plasma 6

- `libkf6coreaddons-dev`
- `libkf6kcmutils-dev`
- `build-essential`
- `qt6-base-dev`
- `qmake6`

#### No Plasma 5

- `libkf5coreaddons-dev`
- `libkf5kcmutils-dev`
- `build-essential`
- `qtbase5-dev`
- `qt5-qmake`
